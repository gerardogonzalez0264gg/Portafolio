# Limpieza y Preparación del Dataset Spotify 2023

## Descripción
En este proyecto se aplicó un proceso de limpieza de datos al dataset Spotify 2023.

## Objetivos
- Identificar e imputar valores nulos.
- Detectar y tratar outliers mediante IQR.
- Codificar variables categóricas.
- Exportar un dataset limpio.

## Herramientas
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab
